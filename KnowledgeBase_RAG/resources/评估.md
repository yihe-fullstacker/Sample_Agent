# 教育学知识笔记（教资考点）

## 一、中国古代教育思想

### （一）孔子主要思想

**教育对象**：有教无类。主张人人都应该接受教育，打破了贵族对教育的垄断。

**教育目的**：培养士和君子。君子应具备仁、智、勇等品德。

**教学原则**：
1. 因材施教：根据学生的不同特点采取不同的教学方法。
2. 启发诱导：不愤不启，不悱不发。
3. 学思结合：学而不思则罔，思而不学则殆。
4. 谦虚笃实：知之为知之，不知为不知。

**教学内容**：六经（诗、书、礼、易、乐、春秋），重视道德教育。

**教育作用**：教育可以改变人的命运，促进社会和谐。

### （二）孟子主要思想

**人性论**：人性本善。人先天具有仁、义、礼、智四个“善端”。

**教育作用**：发扬善端，培养道德完人，得天下英才而教育之。

**教学原则**：循序渐进，专心有恒。

**教育目的**：培养“大丈夫”人格，富贵不能淫，贫贱不能移，威武不能屈。

### （三）荀子主要思想

**人性论**：性恶论。认为人的本性是恶的，善德是后天习得的，强调“化性起伪”，重视教育的作用。

**教学原则**：学以致用，锲而不舍。

**教育作用**：通过教育改造人的本性，使人向善。

### （四）《学记》主要思想

《学记》是中国古代最早的教育专著，系统总结了先秦时期的教育经验。

**教学原则**：
1. 教学相长：教与学相互促进，“学然后知不足，教然后知困”。
2. 豫时孙摩：预防为主、及时施教、循序渐进、相互观摩。
3. 长善救失：发扬学生优点，纠正学生缺点。
4. 启发诱导：道而弗牵，强而弗抑，开而弗达。

**学制设想**：提出了从小学到大学的完整学制。

### （五）其他先秦教育思想

**墨子**：主张“兼爱”“非攻”，重视科技和实用知识教育，提出“素丝说”。

**道家**：主张“自然无为”，反对人为教育对人性的束缚。

## 二、西方教育思想

### （一）夸美纽斯主要贡献

夸美纽斯是捷克教育家，被誉为“教育学之父”。

**主要著作**：《大教学论》。

**核心主张**：
1. **泛智教育**：主张把一切知识教给一切人。
2. **班级授课制**：系统论述班级授课制，提出学年制。
3. **教育适应自然**：教育应遵循自然秩序和儿童发展规律。
4. **直观教学**：强调感官经验在认识中的作用。

**学年制**：把一年分为若干学期，规定统一的开学、放假时间。

### （二）赫尔巴特主要思想

**教育性教学**：教学中必须贯穿德育。

**四段教学法**：明了、联合、系统、方法。

**兴趣理论**：把兴趣分为经验的兴趣和同情的兴趣。

### （三）杜威主要思想

**教育即生活、教育即生长、教育即经验的改造**。

**学校即社会**：把学校办成雏形的社会。

**从做中学**：强调在活动中学习。

**儿童中心**：反对传统的教师中心和教材中心。

### （四）巴班斯基的教育理论

巴班斯基是苏联教育家，提出**教学过程最优化**理论。

**核心内容**：
1. 在一定条件下，用最少的时间和精力，取得最好的教学效果。
2. 强调综合规划教学任务、优选教学内容和教学方法。
3. 注重教学过程中的反馈和调控。

### （五）课程现代化的三大代表人物

1. **布鲁纳**（结构主义课程论）：强调学科基本结构，提倡发现学习。
2. **瓦·根舍因**（范例教学）：通过典型范例掌握学科本质。
3. **赞科夫**（发展性教学）：强调高难度、高速度、理论知识起主导作用等五条教学原则。

## 三、教育的本质与功能

### （一）教育的本质属性

教育是有目的地培养人的社会活动。这是教育区别于其他社会现象的根本特征。

**教育的社会属性**：
1. 永恒性：教育与人类社会共始终。
2. 历史性：不同历史时期教育有不同特点。
3. 相对独立性：教育有自身的规律，不完全依附于政治经济。

### （二）教育的社会功能

**教育对政治的作用**：
1. 培养政治人才，促进政治民主化。
2. 传播一定的政治理念，形成舆论。
3. 通过教育提高国民素质，巩固政权。

**教育对经济的作用**：
1. 再生产劳动力。
2. 再生产科学技术知识。
3. 促进经济增长。

**教育对文化的作用**：
1. 传递和保存文化。
2. 活化文化。
3. 选择文化。
4. 创造和更新文化。

### （三）原始社会的教育形态特点

1. 教育与生产劳动相结合，没有专门的教育机构和专职教师。
2. 教育内容简单，以生活和劳动技能为主。
3. 教育具有原始性、平等性，无阶级性。
4. 教育手段主要靠口耳相传和行动模仿。

## 四、教学原则与教学方法

### （一）常用教学原则

1. **直观性原则**：通过实物、模型、语言等让学生获得感性认识。
2. **启发性原则**：调动学生主动性和积极性。
3. **循序渐进原则**：按照学科逻辑和认知顺序进行教学。
4. **巩固性原则**：及时复习，使知识牢固掌握。
5. **因材施教原则**：根据学生个别差异进行有针对性教学。
6. **理论联系实际原则**：把书本知识与实际生活相结合。

### （二）常用教学方法

1. 讲授法
2. 谈话法
3. 讨论法
4. 演示法
5. 实验法
6. 练习法
7. 参观法

## 五、德育原理

### （一）德育过程的基本规律

1. 德育过程是知、情、意、行统一发展的过程。
2. 德育过程是促进学生思想内部矛盾斗争的发展过程。
3. 德育过程是组织学生的活动和交往，统一多方面教育影响的过程。
4. 德育过程是一个长期的、反复的、逐步提高的过程。

### （二）德育原则

1. 导向性原则
2. 疏导原则
3. 尊重学生与严格要求学生相结合原则
4. 教育影响的一致性与连贯性原则
5. 因材施教原则
6. 知行统一原则
7. 正面教育与纪律约束相结合原则

### （三）德育方法

1. 说服教育法
2. 榜样示范法
3. 陶冶教育法
4. 实际锻炼法
5. 品德评价法
6. 修养法（自我教育）

## 六、课程与教学评价

### （一）课程类型

1. 学科课程与活动课程
2. 分科课程与综合课程
3. 必修课程与选修课程
4. 显性课程与隐性课程
5. 国家课程、地方课程与校本课程

### （二）教学评价类型

1. **诊断性评价**：教学前进行，了解学生起点。
2. **形成性评价**：教学过程中进行，及时反馈。
3. **总结性评价**：教学结束后进行，判断最终效果。

按评价主体：自评与他评。

按评价标准：相对评价、绝对评价、个体内差异评价。

## 七、教师与学生

### （一）教师的职业角色

1. 传道者
2. 授业解惑者
3. 示范者（榜样）
4. 研究者
5. 管理者
6. 朋友
7. 心理辅导员

### （二）教师专业发展

教师专业发展的阶段通常包括：关注生存阶段、关注情境阶段、关注学生阶段。

### （三）学生观

现代学生观强调：
1. 学生是发展中的人。
2. 学生是独特的人。
3. 学生是具有独立意义的人。

## 八、教育法律法规要点（简要）

1. 《中华人民共和国教育法》：教育基本法。
2. 《中华人民共和国义务教育法》：实施九年义务教育。
3. 《中华人民共和国教师法》：保障教师合法权益，规定教师权利与义务。
4. 《中华人民共和国未成年人保护法》：保护未成年人的身心健康和合法权益。
5. 教师职业道德规范：爱国守法、爱岗敬业、关爱学生、教书育人、为人师表、终身学习。
